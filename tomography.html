Reconstructing an entangled state

A source makes pairs of entangled photons. You can't look at the state directly, but you can measure each photon in a few different ways and count what comes out. From those counts you can rebuild the whole state. This is quantum state tomography, and here you get to do it yourself.

01

The source

In a nonlinear crystal such as BBO, a pump photon at 405 nm now and then splits into two photons at 810 nm. This is spontaneous parametric down-conversion. Stack two thin crystals with their axes at right angles and the pair comes out in a superposition: both photons horizontal, or both vertical.

|ψ⟩ = cos θ |HH⟩ + eiφ sin θ |VV⟩

Here you set that state yourself. θ balances the two terms, φ is the phase between them, and the visibility V mixes in white noise, the way imperfect alignment and timing do in a real source. The full state is then

ρ = V |ψ⟩⟨ψ| + (1 − V) 𝟙/4

We call one photon Alice's and the other Bob's.

02

Measuring one photon

One detector click tells you very little. To learn a polarisation state you project each photon onto one of six states: horizontal, vertical, diagonal, anti-diagonal, and right- and left-circular. They sit in opposite pairs on the Poincaré sphere, one pair per axis.

In the lab each arm has a quarter-wave plate, a half-wave plate and a polarising beam splitter that passes H. Turning the two plates picks which state reaches the detector. The angles below come from the same model the simulation uses.

Why six and not two? Measuring only H and V tells you how much of each there is, but nothing about the phase between them. D/A and R/L are what reveal the phase, and the phase is where the entanglement lives.

03

Counting coincidences

Set Alice's analyser to one state and Bob's to another, then count how often both detectors click within a few nanoseconds of each other. That count is proportional to the probability ⟨ab|ρ|ab⟩ of finding the pair in |a⟩|b⟩.

Photon counting is random. A setting that should give 400 counts gives 400 ± 20 or so, because the noise grows as √N. On top of that, unrelated photons sometimes arrive together by chance. These accidentals add a flat background, which is usually subtracted.

04

Linear inversion

Any two-photon polarisation state can be written with 16 real numbers, the two-photon Stokes parameters Sij:

ρ = ¼ Σi,j Sij σi ⊗ σj

Each coincidence count is a fixed linear combination of these 16 numbers. If your settings give 16 independent equations, you can solve for all of them with ordinary linear algebra. With more than 16 the page takes the least-squares fit.

There's a catch. Noise can push the answer outside the set of physical states. A real density matrix never has a negative eigenvalue, but linear inversion can produce one, especially when counts are low.

05

Maximum likelihood

Instead of solving the equations exactly, ask a different question: of all the physical states, which one makes the counts you actually saw most likely? The answer is always a valid state, with no negative eigenvalues, and it uses the data more sensibly when counts are low.

This page finds it with the iterative R·ρ·R method. It starts from the completely mixed state and repeatedly nudges ρ toward the data, keeping it positive at every step.

06

How good is it?

Three numbers sum up the reconstruction. Fidelity says how close it is to the true state, from 0 to 1. Purity, Tr ρ², is 1 for a pure state and ¼ for complete noise. Concurrence measures entanglement: 0 for a state that could be made without it, 1 for a Bell state.

Things to try
  • Raise the integration time and measure all 36 again. Fidelity creeps toward 1, but each tenfold increase in counts only cuts the error by about three.
  • Set |Φ⁺⟩ and lower V. Concurrence falls to zero at V = ⅓, even though the state still shows strong correlations in H/V.
  • Try a mystery state with the standard 16 and see how close you get before revealing it.

Conventions: |D⟩ = (|H⟩ + |V⟩)/√2, |R⟩ = (|H⟩ + i|V⟩)/√2, so S₃ > 0 is right-circular, as in the polarisation game. Pauli operators map to S₁ = σz (H/V), S₂ = σx (D/A), S₃ = σy (R/L). Waveplates are ideal and detectors identical.
